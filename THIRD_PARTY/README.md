# Augur Windows dependency notices

Cargo archives match both committed Cargo.lock files. Python wheels match exact PyPI release hashes.
Tokenizers wheel omits LICENSE; the notice is supplied from its exact PyPI source release, with proof.
Vendor archive hashes, signed MSVC REDIST identities, CUDA EULA and redistribution lists are retained.
Third-party terms remain applicable; the project license does not replace them.
The inventory is resolved dependency scope, not a claim that every Rust crate is linked.
Model weights, Windows and NVIDIA drivers are not bundled. This is not legal advice.
